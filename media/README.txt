Put your clips and posters in this folder.

Naming: 01.mp4 + 01.jpg, 02.mp4 + 02.jpg, and so on.
Preview clips: 10 to 15 seconds, muted, 1080p, H.264 MP4, under 8 MB each.
Posters: a still frame from each clip, JPG, 1600px wide.

Then in edit mode, type the file name (e.g. media/01.mp4) into
"Preview clip file" and "Poster image file" for that project.
